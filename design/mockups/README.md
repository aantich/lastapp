# Approved console mockups

The approved "Ink & Signal" console designs: `Prototype.dc.html` (whole console), `Main.dc.html` (shell and Home), `Entity.dc.html` (entity designer). Open them in a browser.

They define layout and visual style only, never content: the console shows real data (see DEVELOPMENT.md, "Console UI library"). Change a mockup only together with an approved design change.
