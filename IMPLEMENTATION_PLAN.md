# Lastapp implementation plan index

The initial provisioning, shared authorization, business entity/runtime and management MCP stages are implemented. Start with [DEVELOPMENT.md](DEVELOPMENT.md) for current architecture, APIs, source contracts, supported boundaries and verification commands. [VERIFICATION.md](VERIFICATION.md) records what was actually tested.

Historical plans remain available: [provisioning](PROVISIONING_PLAN.md), [Space/authorization](SPACE_AUTHORIZATION_PLAN.md) and [entities](ENTITY_DESIGN_IMPLEMENTATION_PLAN.md). Use the current [foundation](FOUNDATION.md), [entity](ENTITY_RUNTIME.md) and [MCP](MCP.md) guides when a proposed route or milestone differs from the implementation. Do not interpret an old plan as a request to implement deferred features.

Micro-app source/build/static hosting, shared client design packages, WebContainer/WASM runners, external connectors and App container scheduling remain future work. [CONCEPT.md](CONCEPT.md) preserves that direction; implementation scope must be agreed before adding another runtime or service.
